# خطة إعادة بناء نظام التصميم بالكامل (Design System Rebuild v4)

## التحليل النهائي — الحالة الراهنة

المشروع يمتلك نظام v3 سليم المبنية لكنه **غير مطبّق باتساق**. النتائج الرئيسية:
- **74 ملف cshtml** (54 صفحة + 20 partial). 3 ثيمات موجودة + print.
- **Tabulator محمّل عالمياً لكنه غير مستخدم إطلاقاً** (18 صفحة تستخدم HTML tables يدوية) → dead dependency.
- **Chart.js token bug**: `Home/Index` يقرأ `--chart-1` لكن `app.css` يعرّف `--color-chart-1` → الرسوم معطّلة.
- **Toastr/SweetAlert2/NProgress** تستخدم stock CSS خام لا يتبع الـ tokens.
- **3 أنماط forms متضاربة**: `_FormField` partial (10) vs inline-style يدوي (Episodes/Publishing) vs مختلط.
- **dead partials**: `_PageHero`, `_CreateEditHeader`, `_Pagination` لا تُستخدم في أي صفحة.
- **`GetStatusDetails`** مكرر محلياً في Episodes/Index بدلاً من `_StatusBadge`.
- **validation-summary مكرر** حرفياً في 12 موضع.
- **`tailwind.css` يتضارب مع `app.css`**: `nav-link`, `glass-sidebar`, `glass-topbar`, `tabulator` overrides — كلها dead code.

القرار: **إعادة بناء كامل من الصفر** + **تطبيق على جميع الصفحات**.

## المرحلة 0 — الأساس: Design Tokens الجديدة (OKLCH)

**ملف**: `Radio.Web/wwwroot/css/app.css` (إعادة كتابة كاملة)

إنشاء نظام tokens جديد قائم على **OKLCH** (perceptual color science) مع درجات كاملة 50–950 لكل لون دلالي. هذا يحقق تناغماً علمياً بين الدرجات بدل الهيكس العشوائي.

### 0.1 Primitive Palettes (OKLCH → hex)
6 لوحات كاملة (gray/blue/amber/green/red/sky) بدرجات 50–950، محسوبة في OKLCH لضمان L* متسلسل. كل لوحة 11 درجة.

### 0.2 Semantic Tokens — 4 ثيمات
لكل ثيم (Light / Dark / High-Contrast-Light / High-Contrast-Dark):
- **Surface hierarchy**: `bg`, `surface`, `surface-hover`, `surface-elevated`, `popover`, `muted`, `sidebar`, `topbar` (8 طبقات — يحل ازدواجية `bg-elevated`/`surface-elevated`)
- **Text**: `text`, `text-secondary`, `text-muted`, `text-disabled`, `text-inverse` (5 مستويات)
- **Border**: `border`, `border-light`, `border-strong`, `border-focus` (4 مستويات — يحل غياب `border-strong`)
- **Primary/Accent/Success/Warning/Danger/Info**: كل واحد بـ `base/hover/active/foreground/subtle/border/light` (7 حالات × 6 ألوان = 42 token)
- **Status badges**: 9 حالات (planned/executed/published/website/cancelled/preproduction/filming/postproduction/readytoair) × bg/text
- **Charts**: `chart-1..6` + `chart-grid` (إضافة chart-6)
- **Live (On-Air)**: live/foreground/subtle/border

### 0.3 Elevation System (6 مستويات)
`--elevation-0` (flat) → `--elevation-5` (modal). يحل محل `--shadow-card/card-hover/float/topbar/drawer/modal/dropdown` المتشتتة بنظام موحد قابل للتوسع. كل elevation = box-shadow token.

### 0.4 Typography Scale (CSS tokens + Tailwind classes)
مقياس موحد: `--text-display/-headline/-title-lg/-title/-body-lg/-body/-label/-caption/-micro` مع font-size + line-height + letter-spacing لكل مستوى. يُربط بـ Tailwind classes: `text-display`, `text-headline`, إلخ. يحل `text-[10px]`/`text-[11px]` العشوائية.

**الخط**: الإبقاء على **Cairo** (موجود، عربي ممتاز، يدعم الأوزان 300–800). قرار مبرر: Cairo يتفوق على Inter/Geist لدعم العربية RTL، ويتوافق مع المعايير العالمية للأرقام tabular. لا حاجة لخط بديل.

### 0.5 Spacing (8pt grid) + Radius + Motion
- Spacing: `--space-1..16` (0.25rem → 4rem) + `--sidebar-width`, `--topbar-height`, `--btn-height-sm/md/lg`, `--input-height`
- Radius: `--radius-xs/sm/md/lg/xl/2xl/3xl/full` (2/4/6/8/12/16/20/24/9999) — موسع عن الحالي
- Motion: `--duration-instant/fast/normal/slow/slower` + `--ease-standard/emphasized/exit` + reduced-motion fallback

### 0.6 Z-index scale موحد
`--z-base/dropdown/sticky/sidebar/overlay/modal/toast/tooltip` (يحل القيم المبعثرة z-30/40/50/9999).
